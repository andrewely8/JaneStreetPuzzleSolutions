If our solution needs to be accurate to 10 decimal places, that gives 10,000,000,000 options.

Regardless of the homerun probability p:
From the pitcher's perspective, if the batter swings, the pitcher should throw a ball. If the batter doesn't swing, the pitcher should throw a strike.
From the batter's perspective, if the pitcher throws a strike, the batter should swing. If the pitcher throws a ball, the batter should not swing.
Because if it is known the pitcher throws a strike, the batter doesn't need to worry about his chance of hitting a homerun, he should swing no matter what since 
if he doesn't swing he gets a strike anyway.

-Our game is zero sum.
-We have no pure strategy Nash equilibrium. We need a mixed strategy.
-We can consider our game as just one instance of at bats. The game either ends in a score of 0, 1, or 4.
-So the game is finite, we don't need to worry about "infinite number of at bats" because each at bat can just be considered the game itself. We have two players, fixed rules, and a
declared winner or loser.

Since our game is zero sum, we have the following, based on https://www3.nd.edu/~apilking/math10170/information/Lectures/16%20Optimal%20Mixed%20Strategy.pdf

    	    		 swing      don't swing

PITCHER		    |_____________|_____________|
		    |             |             |
	(1-t) ball  |      c      |     d       |
		    |_____________|_____________| 


Where the matrix [[a,b],[c,d]] is the payoff matrix for the pitcher. Since we are zero sum, the payoff matrix for the Batter will be [[-a,-b],[-c,-d]].

[t,1-t] * [[a,b],[c,d]] * [s,1-s] = (ad-bc)/(a-b-c+d) - (a-b-c+d)*(t - (d-c)/(a-b-c+d))*(s - (d-b)/(a-b-c+d))

We want to set t so that the choice of s can't affect the expected value for the pitcher, and we want to set a s vice versa.

t = (d-c)/(a-b-c+d)   s = (d-b)/(a-b-c+d)

And we know b=c because if a ball is thrown and the batter swings, a strike is recorded, and if a strike is thrown and the batter doesn't swing a strike is recorded. Same payoff. So,

t = (d-b)/(a-2b+d)   s = (d-b)/(a-2b+d)

So, t = s = (d-b)/(a-2b+d)


Now we need to decide what the payoff values (a,b,d) are. We have two variables strikeCount and ballCount that influence the Score in the end. 
If we are on the first pitch, the count is (0,0) representing 0 balls and 0 strikes. If b (or c, since c=b) occurs, then we advance to the count (0,1). If d occurs, we advance to the count (1,0). 
If 'a' occurs, with probability p the game ends and the score is 4, and with probability 1-p we advance to the count (0,1). 
Then for the second pitch, the same logic holds except instead of being at count (0,0) we will either be at count (0,1) or (1,0), and the advancements will result in (1,1) or (0,2) or (2,0).
